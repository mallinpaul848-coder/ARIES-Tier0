# Phone Recovery Toolkit

A separate, static informational app for owner-authorized phone recovery.

## What it covers
- iPhone passcode / Apple Account recovery and Activation Lock support route
- Android screen-lock recovery and data-loss warnings
- Google Factory Reset Protection (FRP) official account recovery
- Samsung Galaxy Device Protection
- Carrier/SIM network unlock requests
- Company/school-managed device release

## Safety and limits
This is not an exploit, bypass utility, forensic unlocker, or manufacturer service. It does not defeat Activation Lock, Google FRP, carrier controls, or mobile-device management. Those protections require the linked account, authorized administrator, carrier approval, or manufacturer ownership review. A factory reset may erase data and does not inherently remove Activation Lock or FRP.

## Open
Open `index.html` in a modern browser. It is a static guide and does not require a backend or send user input to a server.
