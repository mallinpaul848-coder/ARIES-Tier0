Validation policy

No fabricated scores

This dashboard does not claim that ARIES has achieved sub-nanosecond inference, passed an independent leaderboard, or completed live dispatch bookings. The benchmark report must include raw measurements, hardware/software details, repeatability, and a clearly defined workload. Public model validation must verify non-empty responses and functional correctness—not merely HTTP 200.
