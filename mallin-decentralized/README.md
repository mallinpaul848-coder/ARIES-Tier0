# MALLIN Platform — ARIES AI chat shell

A static, mobile-friendly chat interface with a purple cosmic theme, an offline app shell, basic local arithmetic, and an optional OpenAI-compatible endpoint field.

## Status and honest limitations

- This is a **front-end prototype**, not a bundled language model.
- Local demo mode is not general-purpose AI inference.
- The optional endpoint works only if you operate a compatible server and it permits browser requests (CORS).
- No independent evaluation or certification is claimed.
- The public website is not considered live until a server under your control is running and external access has been tested.

## No third-party hosting route

You explicitly do not want Vercel, Render, Netlify, hosted tunnels, or hosted IPFS pinning. The folder now contains a small static-file server and launch scripts intended for hardware you control.

**Start here:** [Self-hosting without a hosting company](SELF-HOST-NO-THIRD-PARTY.md)

- `server.py` serves only the known static assets; it has no upload/write routes.
- `START-ON-ANDROID-TERMUX.sh` starts it on an Android phone with Termux and Python installed.
- `START-ON-WINDOWS.cmd` starts it on Windows with Python 3 installed.

The Android phone can be the always-on device instead of a PC, if it remains powered and on home Wi-Fi. To publish it beyond your home network, the router/ISP must allow inbound connections. If your ISP uses CGNAT and will not give you a public IP, direct public access without a relay or host is not possible on that connection. The current starter server is HTTP-only demo tooling, not a finished secure production server. Read the guide before exposing it publicly.

## Files

- `index.html` — app shell and chat layout
- `styles.css` — responsive purple cosmic theme
- `app.js` — local demo, endpoint settings, chat requests
- `manifest.webmanifest` — installable web app metadata
- `sw.js` — caches the static app shell for offline revisits
- `server.py` — minimal allowlisted static server for controlled self-hosting

## Test locally

Start the server from this folder, then open `http://127.0.0.1:8080/` in a browser. Try `Calculate 128 * 64`, clear the chat, and check the status. The default is a demo. To test real inference, configure a compatible model endpoint that you control and verify the answer is generated by that model.

## AI backend

The site itself does not add model weights or inference compute. If you also reject external AI APIs, actual model inference must run on hardware you control separately from this static web server.
