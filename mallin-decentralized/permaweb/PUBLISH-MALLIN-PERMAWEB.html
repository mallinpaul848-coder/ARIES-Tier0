Availability and cost

This is not a traditional web-hosting server. The file is stored on Arweave. Ordinary browsers use a gateway to retrieve it; gateway and network reliability remain external dependencies. The uploader will not pay or fall back to a paid upload.

Official documentation currently says mainnet files up to 105 KiB can be uploaded free if the wallet/IP lifetime allowance remains; the current lifetime limit is 10 MiB. If the free allowance is exhausted or the service refuses the request, the tool stops and reports the error. It will not request a payment or crypto wallet key. Official upload rules.
