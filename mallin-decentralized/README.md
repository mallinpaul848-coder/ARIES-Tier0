# MALLIN Platform — ARIES AI chat shell

A static, mobile-friendly chat interface with a purple cosmic theme, an offline app shell, basic local arithmetic, and an optional OpenAI-compatible endpoint field.

## Important status

- This is a **front-end prototype**, not a bundled language model.
- The default local demo is not general-purpose AI inference.
- The optional endpoint is only useful if you operate a compatible server and it allows browser requests (CORS).
- Endpoint configuration and a successful `/models` check do not prove that chat completions work.
- No independent evaluation or certification is claimed.

## Files

- `index.html` — app shell and chat layout
- `styles.css` — responsive cosmic theme
- `app.js` — local demo, endpoint settings, chat requests
- `manifest.webmanifest` — installable web app metadata
- `sw.js` — caches the static app shell for offline revisits

## Test locally

Serve this folder over HTTP (service workers do not run from ordinary `file://` URLs), then open it in a modern browser. Try `Calculate 128 * 64`, clear the chat, and check the status. To test real inference, configure a compatible endpoint that you control and send a prompt; verify that the answer is generated by your model.

## Public deployment

The repository's default branch is private. A public site still requires an enabled hosting/publishing target and a successful deployment. GitHub Pages publishes static files but does not run the Python model backend. Do not describe this prototype as publicly live until a deployment URL is verified.
