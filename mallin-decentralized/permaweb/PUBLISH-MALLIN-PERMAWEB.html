MALLIN PLATFORM · PERMANENT PUBLICATION

Publish MALLIN to the permanent web

This submits the current single-file MALLIN page to Arweave permanent storage. The website will not be served from your phone or home internet after publication.

One publishing run

  1. Open the GitHub Actions publish page.
  2. Choose Run workflow.
  3. Under confirmation, select yes. Selecting no makes no upload.
  4. Wait for the workflow to finish, then open its summary and copy the public website URL.
Open MALLIN publish workflow ↗

You must be signed in with permission to the repository. If the page reports that GitHub Actions is disabled or requires permission, the upload has not happened.

Permanent public publication

The upload is immutable and public. It publishes the MALLIN interface with browser-local language-model code. Do not publish secrets or personal information. The workflow checks that the file is under 105 KiB, uses a temporary signing key, does not supply payment credentials, and verifies the stored bytes before reporting a verified URL.

What the public site will do

The page includes WebLLM browser inference with two supported model choices. A visitor must have an HTTPS browser with WebGPU and enough GPU memory; the first visit downloads the runtime and model weights. Inference runs on that visitor's device and no AI chat API is called.

This is not the project's custom ARIES weights; these are supported pretrained starter models. Public storage availability is decentralized, but ordinary browsers still access it through gateways, and runtime/model artifacts are downloaded from public repositories.
